# Nguồn chính thức — Unity và Windows

Rà và cập nhật ngày **2026-11-15, Asia/Saigon**. Đây là nghiên cứu tài liệu, không bằng chứng đã cài/chạy.
Trang nào không ghi ngày cập nhật trên bài gốc được đánh dấu rõ; phải xác minh checksum installer và release notes mới hơn tại thời điểm `P00-04`/`B00-02` trước khi cài hoặc trả phí.
